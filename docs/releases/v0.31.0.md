GCC 0.31.0 adds independently checkable finite-domain firmware certificates and strengthens self-service firmware and RTL evaluation.

## Release highlights

- **Firmware predicate certificates:** Represent six valid OpenTitan PWM behaviors and all 250 invalid runtime channels with deterministic, source-bound evidence.
- **Independent verification:** Replay every invalid input with ordinary scalar machines and refuse source, symbol, route, artifact or semantic drift.
- **Static safe fallback:** Select the specialized predicate route only from bounded preflight structure and preserve complete exact execution for divergent firmware.
- **Compiled firmware integrity:** Match pinned O0 and O2 RV32IMC images with an independently compiled native recorder across all 256 inputs.
- **Safer file workflows:** Harden compiled-MMIO input loading and certificate publication against symlink, rename, replacement and concurrent-write races.
- **RTL evaluation:** Expand source-attested OpenTitan PWM property and trace workflows with governed Rust APIs, resource telemetry and maintained-tool comparisons.
- **Compatibility:** Advance the additive research API to 0.31.0, retain existing operation discriminants and update optional QatQ transport to 0.1.5.

## Measured certificate result

| Profile | Complete certificate transitions | Exact transitions | Reduction | Peak RSS |

| O0 | 26,775 | 629,636 | 23.52x | 10.81 MiB |
| O2 | 9,264 | 231,920 | 25.03x | 4.39 MiB |

Complete certificate work includes preflight, production and independent verification.
The figures apply to the retained OpenTitan PWM firmware cohort and are not universal solver-performance claims.

## Install

Complete research build:

```sh
cargo install guarded-continuation-checker --version 0.31.0 --locked
```

Frozen firmware and RTL profile:

```sh
cargo install guarded-continuation-checker --version 0.31.0 --locked \
  --features production-firmware
guarded-continuation-checker production-profile-version
```

## Status and scope

GCC is an evaluation-ready research prototype, not a production-qualified or certified verification product.

This release establishes a bounded proof-carrying firmware mechanism and fail-closed integration path. It does not claim a universally faster solver, a general firmware-to-RTL proof or a proven novel algorithm.
