GCC 0.32.1 refreshes runtime dependencies, optional research transport and release tooling while preserving existing verification contracts and evidence formats.

## Release highlights

- **Runtime dependencies:** Update libc to 0.2.191 and SHA-2 to 0.11.1, including upstream AArch64 round-constant loading fixes.
- **Research transport:** Update optional QatQ transport to 0.4.2 while keeping it outside the frozen production firmware feature.
- **Release tooling:** Update pinned artifact upload and attestation actions to 7.0.2 and 4.2.2.
- **Compatibility:** Preserve public APIs, CLI contracts and canonical evidence formats.

## Install

```sh
cargo install guarded-continuation-checker --version 0.32.1 --locked
```

For the frozen firmware and RTL profile:

```sh
cargo install guarded-continuation-checker --version 0.32.1 --locked \
  --features production-firmware
guarded-continuation-checker production-profile-version
```

## Status and scope

GCC remains an evaluation-ready research prototype, not a production-qualified or certified verification product. This maintenance release adds no new verification capability or performance claim.
