# Guarded Continuation Checker v0.30.0

GCC 0.30.0 introduces proof-carrying revision-impact analysis for bounded
firmware and RTL verification.

This release can show whether a source change merely invalidates old evidence,
or actually changes a bounded SAFE or UNSAFE result. The certificate binds the
complete old and new counterfactual table to independently checkable,
revision-local evidence.

## What is new

- Deterministic revision-impact certificates with strict, no-fallback
  verification
- A self-service file CLI and typed Rust interfaces with resource limits and
  work observability
- A connected OpenTitan PWM evaluation covering 20 observations across
  core-only, channel-only and combined changes
- Hosted Linux reproduction of the public artifact and all nine hostile-drift
  rejection cases
- Agreement with maintained Yosys, rIC3 and Certifaiger evidence on all 9 SAFE
  and 11 UNSAFE observations
- A crates.io-backed Rust API compatibility gate
- QatQ 0.1.4 exact-byte container integration for the research transport path

## Measured result

On the matched OpenTitan cohort, the shared GCC workflow was about 53.78 times
faster from source to answer than 20 isolated maintained-tool jobs and used
about 20 percent less producer-path peak memory. Its artifact was about 8.32
times larger.

These measurements describe this specific shared-model experiment. They are not
a universal solver-performance claim.

## Install

Complete research build:

```sh
cargo install guarded-continuation-checker --version 0.30.0 --locked
```

Frozen firmware and RTL profile:

```sh
cargo install guarded-continuation-checker --version 0.30.0 --locked \
  --features production-firmware
guarded-continuation-checker production-profile-version
```

The reported production-profile capability remains:

```text
production_support_profile=firmware-rtl-v1 firmware_cli_version=2 artifact_schema_version=4
```

Revision impact and QatQ transport remain research surfaces and are not part of
`firmware-rtl-v1`.

## Project status

GCC is an evaluation-ready research prototype. It is not a
production-qualified or certified verification product.

Incremental proof reuse, mutation impact, compositional verification and
multi-property checking all have substantial prior art. This release
demonstrates a narrow source-bound certificate and self-service workflow. It
does not claim a proven novel algorithm.
